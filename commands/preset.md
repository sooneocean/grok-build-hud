---

# HUD presets

```bash
grok-build-hud --preset full        # 3 rows (default)
grok-build-hud --preset essential   # 2 rows
grok-build-hud --preset minimal     # 1 compact row
```

Or open the settings UI:

```bash
grok-hud settings
```

Presets keep your language preference (中文 / English).
