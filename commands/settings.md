# Settings

```bash
grok-hud settings
# or
grok-build-hud --settings
```

## Language shortcuts

```bash
grok-hud lang en   # English (default)
grok-hud lang zh   # 简体中文
grok-hud lang tw   # 繁體中文
```

Config file: `~/.grok/hud/config.json` → `language`
